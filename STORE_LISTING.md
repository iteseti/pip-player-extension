# Материалы для публикации в Chrome Web Store

## Пакет
`pip-extension-v1.0.0.zip` — готов к загрузке в [Chrome Web Store Developer Dashboard](https://chrome.google.com/webstore/devconsole).

Требуется аккаунт разработчика Chrome Web Store (разовый платёж $5).

## Название
PiP Player — картинка в картинке для любого видео

## Краткое описание (132 символа макс.)
Видео в окне поверх всех окон: пауза, громкость, скорость, кадрирование области, мини-режим, полный экран. Работает на YouTube и других сайтах.

## Полное описание
PiP Player открывает любое видео со страницы в отдельном окне «картинка в картинке» поверх всех окон — с полноценными элементами управления, которых нет у стандартного PiP.

Возможности:
• Пауза/воспроизведение кликом по видео, кнопкой или пробелом
• Громкость, скорость воспроизведения (0.25×–2×), прогресс-бар
• Кадрирование: выделите рамкой нужную область (вебку стримера, чат) — окно покажет только её
• Режим «заполнить окно» с панорамированием мышью
• Мини-режим: чистое окно без панели, кнопки по наведению
• Разворачивание окна на весь экран
• Автоскрытие панели — ничего лишнего
• Горячие клавиши: Alt+P на странице; в окне — Space, M, F, C, стрелки
• Левый клик по иконке — открыть PiP, правый — настройки

Не собирает данные, не отправляет ничего в сеть. Работает локально.

## Обоснование разрешений (заполнить в дашборде)
- `storage` — сохранение настроек пользователя (скорость, режим кадра, громкость)
- `activeTab`, `scripting` — внедрение кнопки PiP и перенос видео в окно по действию пользователя
- `contextMenus` — пункт «Настройки» в меню иконки расширения
- `host_permissions: <all_urls>` — расширение работает с видео на любых сайтах по клику пользователя

## Политика конфиденциальности
«Расширение не собирает, не хранит и не передаёт никаких пользовательских данных. Все настройки хранятся локально в chrome.storage.sync.»
