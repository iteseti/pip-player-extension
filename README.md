# PiP Player — картинка в картинке для Chrome

Расширение открывает любое видео со страницы в отдельном окне поверх всех окон
(Document Picture-in-Picture, Chrome 116+) со своими элементами управления.

## Скачать

Готовый пакет — в разделе [Releases](../../releases): скачайте `pip-extension-vX.X.X.zip`
и распакуйте в любую папку.

## Установка

1. Откройте `chrome://extensions`
2. Включите «Режим разработчика» (Developer mode) в правом верхнем углу
3. Нажмите «Загрузить распакованное расширение» (Load unpacked)
4. Выберите папку с распакованным расширением
5. Откройте страницу с видео (YouTube, VK Видео и т.д.), наведите курсор на видео
   и нажмите появившуюся кнопку PiP — или `Alt+P`

## Возможности

- ⏯ Пауза / воспроизведение — кнопка, `Space` или клик по видео в любом месте
- 🔊 Громкость (ползунок + mute, опционально запоминается)
- ⛶ «Во весь экран»: разворачивает PiP-окно (Chrome 121+); на старых версиях — окно мгновенно переоткрывается сразу на весь экран, повторное нажатие возвращает обычный размер
- ⏩ Перемотка по прогресс-бару и стрелками (±5 с)
- 🖼 Режим кадра: «вписать» / «заполнить окно» (обрезка краёв) — кнопка в панели или `C`, сохраняется
- ✋ Панорамирование в режиме «заполнить»: зажать мышь и тянуть — сдвиг видимого участка, двойной клик — вернуть центр
- ✂ Кадрирование: растянуть рамку мышью по нужной области (вебка, чат) — окно показывает только её; Esc — отмена; в режиме кадрирования при наведении доступны пауза, весь экран и выход
- ✨ Панель контролов лежит поверх видео и автоскрывается (~2 с)
- 🔽 Мини-режим: окно без панели — пауза кликом по видео, кнопки по наведению
- 🚀 Скорость воспроизведения (0.25×–2×, сохраняется)
- 💾 Запоминание размера окна
- ⌨ Горячие клавиши: `Alt+P` на странице; в окне PiP — `Space`, `M`, `F`, `C`, стрелки
- Фолбэк на классический PiP, если Document PiP недоступен

## Использование

- **Левый клик по иконке расширения** — открыть/закрыть PiP на текущей вкладке
- **Правый клик по иконке** → «Настройки PiP Player» — окно настроек
- Кнопка PiP на видео при наведении, либо `Alt+P`

## Настройки

- скорость воспроизведения по умолчанию;
- режим кадра по умолчанию (вписать / заполнить);
- открытие в мини-режиме;
- показ плавающей кнопки на видео;
- запоминание громкости между сессиями.

## Ограничения

- Сайты с DRM (Netflix, Кинопоиск и др.) могут блокировать вывод видео в PiP.
- Настоящий fullscreen внутри PiP-окна запрещён Chrome — используется разворачивание окна.
- Открытие окна требует жеста пользователя по странице (ограничение Chrome):
  при клике по иконке расширения на видео появляется кнопка для подтверждения.
